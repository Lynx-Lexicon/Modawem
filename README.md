# Modawem
A smart pharmacy companion that tracks medication use, predicts refills, detects drug-drug interactions, and gives patients, prescribers, and pharmacists a complete view of medication history and behaviour for more informed decisions

## 📚 Documentation Directory

- **[Infrastructure & Environment Setup](infrastructure/README.md)** - How to start the backend and database for Dev, Staging, and Prod.

## 📁 Repository Structure

- `apps/backend/` - The core Backend API (currently a placeholder).
- `apps/web/` - The Web Application.
- `apps/mobile/` - The Flutter mobile application.
- `ai-services/` - AI and machine learning models.
- `infrastructure/` - Docker Compose and Infrastructure as Code.
- `packages/` - Shared contracts and types.
- `docs/` - Project documentation.
